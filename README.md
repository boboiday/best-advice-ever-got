One sentence, 182 characters, about the best advice I ever received: my father, knuckles bleeding from a stripped bolt in his garage, setting down his spanner and telling me the bolt doesn't care how angry I am — so stop shouting and start turning.

## Run it

Requires Node.js 22. No dependencies, no network, deterministic.

```sh
node main.ts
```

This prints the sentence to stdout and writes the exact same sentence to `/output/entry.txt`.
